# Pila funcionamiento
El codigo comienza importando las herramientas necesarias: tkinter para crear la ventana grafica y sus elementos, y random para elegir colores al azar. Despues, se crea una lista llamada pila, donde se guardan los elementos que escribe el usuario. Luego, el codigo se organiza en varias funciones que permiten mostrar los bloques de colores, agregar elementos, consultar el que esta arriba, quitar el ultimo y vaciar la pila. Para crear la ventana se utiliza tk.Tk(), y con title() y geometry() se establece su nombre y tamaño. Despues se agregan el titulo, el espacio para escribir, los botones, el contador y el area Canvas, donde se dibujan los bloques que representan la pila. Tambien se incluye una barra para desplazarse cuando hay muchos elementos. Cada boton se conecta con una funcion para realizar la accion correspondiente y actualizar la pantalla. Finalmente, mainloop() mantiene la ventana abierta para que el usuario pueda interactuar con el programa. Todo funciona siguiendo la regla de que el ultimo elemento en entrar es el primero en salir.

# Pila funcionamiento
El programa esta desarrollado en Python utilizando la libreria Tkinter para mostrar graficamente el funcionamiento de una pila. Primero, se importan las librerias necesarias y se crean las listas pila, que almacena los elementos, y colores, que contiene los colores disponibles. Despues se definen las funciones: mostrar_pila() dibuja los elementos como bloques de colores; apilar() agrega un nuevo elemento mediante append(); ver_cima() consulta el ultimo elemento; desapilar() elimina el ultimo elemento utilizando pop(); y vaciar_pila() elimina todos los elementos con clear(). Posteriormente, se crea la ventana con tk.Tk() y se agregan el campo de texto, los botones, el contador y el area grafica Canvas. Cada boton ejecuta una funcion y actualiza la pila visualmente. Finalmente, mainloop() mantiene abierta la ventana para permitir la interaccion del usuario. Todo el programa sigue el principio LIFO, que significa que el ultimo elemento en entrar es el primero en salir.
